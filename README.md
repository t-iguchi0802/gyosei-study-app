# 行政書士2026 第1回 学習アプリ

完成済みの第1回予想模試60問と解答解説を、PCとスマホで学習するためのWebアプリです。

## 最新の公開状態（2026-09-29）

[学習アプリを開く](https://gyosei-study-2026-tiguchi.web.app/)

全60問の改修版、参考書21章、別系統の実力確認24問を公開済みです。ホームの「実力確認を始める」から利用できます。主要18ファイルの公開一致と、未ログインの保存・再開・390/1280px表示を確認済み。実機2端末での新しい確認問題の同期は別途確認が必要です。詳しい公開記録と未完了事項は `PROJECT_STATUS.md` を参照してください。

旧60問は従来の5枠保存が残っています。追加24問では全回答を追記保存します。旧60問も含む完全な履歴分離・無制限化が完了したという意味ではありません。

2026-09-29公開済みの改善：通常学習・実力確認の選択肢を1〜5固定順にし、解説に根拠条文の本文と読み方、判例の事案・判断理由・一次資料リンクを表示。条文は2026年4月1日時点の20法令156条を必要部分として同梱。公開20ファイル一致と公開版の固定順・本文表示・再開を確認済み。内容・確認方法は `tools/legal-basis-sources.md`、公開記録は `PROJECT_STATUS.md` を参照してください。

e-Govリンクは法令の冒頭ではなく、基準日の施行版にある該当条文を直接開きます。20法令156条の条文IDを実画面で確認済みです。

## 公開環境

- Firebase Hosting：PC・スマホ共通URL
- Firebase Authentication：Googleログイン
- Cloud Firestore：5回分の解答・正誤・自信度・記述得点を端末間同期
- GitHub：`t-iguchi0802/gyosei-study-app`

PCとスマホで同じGoogleアカウントにログインすると、学習履歴が自動的に統合・同期されます。ログインしていない場合や一時的に通信できない場合も、各端末のブラウザ内には保存されます。

## モード

- 通し試験：全60問を解き終えてから一括採点します。解答中は正解・解説・過去成績を表示しません。
- 1問ずつ復習：1問だけを表示し、「解答・解説」を押した時だけ現在の問題の結果と解説を表示します。
- 5回履歴：各問題の正誤と自信度を5回分保存します。

記述式は、模範解答と必須キーワードを確認して自己採点します。

## v2学習再開機能（本番反映済み）

旧v1データを削除せず、学習モードの再開位置を別のv2領域に保存します。

- ホーム最上部に「続きから学習」を表示
- 5問完了後に終了・再読込しても、問6から再開
- 60問完了時に次の周回へ移行
- 回答と自信度を選ぶまで解説を表示しない
- 同じ周回を複数端末で進めた場合、回答済み問題IDを統合
- 既存v1 localStorage・Firestoreデータは削除しない

端末内のv2保存キー：

```text
gyosei2026_mock1_learning_v2
```

ログイン時のv2同期先：

```text
users/{uid}/apps/gyosei2026Mock1
```

2026-09-27にFirebase Hostingへ反映済みです。旧v1データの削除や一括移行は実施していません。
