# 行政書士2026 第1回 学習アプリ

完成済みの第1回予想模試60問と解答解説を、PCとスマホで学習するためのアプリです。

## PCとスマホで使う

1. `start-app.ps1` を右クリックしてPowerShellで実行します。
2. 画面に表示された `PC` のURLをパソコンで開きます。
3. PCと同じWi-Fiにスマホを接続し、画面に表示された `スマホ` のURLをスマホで開きます。
4. 最初の端末で「同期コードを作る」を押します。
5. もう一方の端末で同じコードを入力し、「同期コードで接続」を押します。

以後、5回分の解答・正誤・自信度がサーバーへ保存され、両端末で共有されます。通信できない場合も端末内には保存され、再接続後に同期します。

現在の構成は同一Wi-Fi内で利用します。外出先を含む常時利用には、このアプリと同期APIをクラウドへ公開する必要があります。

## モード

- 通し試験：全60問を解き終えてから一括採点します。解答中は正解・解説・過去成績を表示しません。
- 1問ずつ復習：1問だけを表示し、「解答・解説」を押した時だけ現在の問題の結果と解説を表示します。
- 5回履歴：各問題の正誤と自信度を5回分保存します。

記述式は、模範解答と必須キーワードを確認して自己採点します。

## 保存先

- 各端末：ブラウザのローカルストレージ
- 共有データ：`storage/profiles.json`

同期コードは学習履歴へアクセスする鍵です。第三者へ公開しないでください。
