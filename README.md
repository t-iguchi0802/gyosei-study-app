# 行政書士スマホ学習アプリ

行政書士試験を短時間で一周するためのスマホ向け静的Webアプリです。

## 使い方

Vercelにデプロイして、発行されたURLをスマホのChromeまたはSafariで開きます。

## 機能

- 講義、要点、問題、進捗の切替
- 基本編68講義と応用編の切替
- 音声読み上げと速度調整
- 間違えた問題の短時間再出題
- 復習優先、苦手優先、未学習優先、全範囲の出題モード
- 理解度、今日の復習数、連続正解数の表示
- 状況に応じた学習コメント
- 要点カード
- 分野別進捗
- 学習記録のブラウザ保存

## 収録分野

- 行政手続法
- 行政不服審査法
- 行政事件訴訟法
- 国家賠償法
- 地方自治法
- 行政法総論
- 記述式

## 復習ロジック

正解すると理解レベルが上がり、次回復習までの間隔が伸びます。不正解の場合は理解レベルを下げ、5分後以降に優先して再出題します。
