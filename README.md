# 行政書士スマホ学習アプリ

行政書士試験の **180点合格** に必要な論点だけを厳選し、**最小の問題数で最大の得点効率** を目指すスマホ専用アプリです。

**本番URL:** https://gyosei-study-app-wheat.vercel.app

**現在の表示バージョン:** `v2026.06.12-1`

## 最終原則

行政書士試験は満点試験ではない。本アプリは **300点を目指さない**。

180点を最短で超えるために、学ぶ論点と学ばない論点を明確に分けます。

迷った場合の判断基準: **「その論点は180点達成に必要か？」**

## 学習方針

| 原則 | 内容 |
|------|------|
| 180点合格 | 法令等122+ / 基礎24+ / 計180+。満点不要 |
| 厳選 | 合格に必要な論点だけ。捨て論点は学習しない |
| 最小問題数 | 完成形 ~212問（現在98問） |
| 最大効率 | 180点ルート＋間隔反復 |
| 形式再現 | 5肢・多肢・記述（40字自由入力） |
| 予測優先 | 法改正・今年度出題可能性 |

詳細: [LOSING_STRATEGY.md](./LOSING_STRATEGY.md)

## 記述式対策について

| 段階 | 内容 |
|------|------|
| **現在** | 31問（選択式による採点語・40字答案の予備訓練） |
| **今後** | 本試験と同じ **40字自由入力＋採点基準付き ~20問** へ再編 |

31問から約20問になるのは問題数を減らすためではなく、MC型の簡易問題を整理し、**本試験形式の高品質な記述訓練** に置き換える方針です。

## 使い方

1. URLをスマホの Chrome / Safari で開く
2. 「180点ルート」で今日の学習メニューを確認
3. 「180点優先」「本試験型優先」「要点チェック」で学習
4. 画面上部のバージョン表示で同期状況を確認
5. ホーム画面追加で PWA 利用可

## 機能

### コンテンツ（現状）

- 問題 **98問**（厳選拡充中、目標 ~212問）
- 講義125 / 要点132 / 体系テキスト / 重要条文要約

### 学習機能

- 8出題モード / **180点ルート** / 間隔反復 / 音声読み上げ
- 記述式: 採点語チェック・40字答案（MC訓練。自由入力は開発中）
- 学習記録は端末の `localStorage` に保存

### 収録分野

行政法6分野 / 民法 / 憲法 / 基礎知識 / 商法・会社法 / 基礎法学 / 記述式

## 復習ロジック

正解すると理解レベルが上がり、復習間隔が伸びます（5分→30分→3時間→1日→3日→7日）。不正解は短時間後に再出題されます。

## 行政書士試験

| 項目 | 内容 |
|------|------|
| 形式 | 60問300点 |
| 合格 | 法令等122+ / 基礎24+ / 計180+ |
| 記述 | 40字×3（60点）。例年 行政法1・民法2 |
| 法令 | 試験年4/1現在施行 |

公式: [行政書士試験研究センター](https://www.gyosei-shiken.or.jp/)
